# AI Model Releases - June 13, 2026

> Daily briefing compiled from web searches on June 13, 2026.

---

## Top Updates

- **Kimi K2.7-Code — Moonshot AI** *(Released June 12)*
  Open-sourced coding-focused agentic model built on Kimi K2.6. Targets software engineering and agentic programming tasks with ~30% lower reasoning-token usage than its predecessor.
  - Context window: 256K tokens
  - License: Modified MIT
  - Status: **Released / Open-source**

- **NVIDIA Nemotron 3.5 Content Safety — NVIDIA** *(Announced this week)*
  Customizable multimodal safety model designed for global enterprise AI deployments. Operates across text, image, and audio modalities, filling a gap in scalable, adaptable safety mechanisms.
  - Modalities: Text, Image, Audio
  - Target: Enterprise
  - Status: **Released**

- **Claude Fable 5 — Anthropic** *(Released June 9)*
  Anthropic's latest flagship model in the Claude family. Represents their most advanced release to date.
  - Status: **Released**

- **DiffusionGemma 26B-A4B — Google** *(Released June 10)*
  Open-source image generation and manipulation model from Google based on the Gemma architecture. 26B parameters with a 4-bit quantized variant (A4B).
  - Parameters: 26B (A4B variant available)
  - License: Open-source
  - Status: **Released**

- **OpenAI Real-Time Audio Models — OpenAI** *(Announced June 2026)*
  Three new real-time audio models for conversational agents, translation, and transcription. Aimed at voice-first and multilingual agent applications.
  - Status: **Released**

- **MAI-Code-1-Flash & MAI-Thinking-1 — Microsoft** *(Released June 2)*
  Two complementary models: MAI-Code-1-Flash optimized for speed in coding tasks, and MAI-Thinking-1 focused on extended reasoning. Both part of Microsoft's MAI (Microsoft AI) model family.
  - Status: **Released**

- **MiniMax M3 — MiniMax** *(Released June 1)*
  Lightweight open-source LLM optimized for efficient deployment. Aimed at developers needing a capable but cost-effective model.
  - License: Open-source
  - Status: **Released**

- **EVA-Bench Data 2.0 — ServiceNow AI** *(Announced this week)*
  Expanded evaluation benchmark for AI agents, covering 3 domains, 121 tools, and 213 scenarios. Designed to standardize agentic capability testing.
  - Status: **Released (benchmark)**
