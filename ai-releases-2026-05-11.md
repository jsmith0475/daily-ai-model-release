# AI Model Releases - May 11, 2026

## Top Updates

- **Gemini 3.1 Ultra — Google**
  Google's most significant model release of the year features a 2-million token context window with native multimodal support across text, image, audio, and video — no transcription intermediaries required.
  Key specs: 2M token context window, natively multimodal. Status: Released.

- **GPT-5.5 / GPT-5.5-Cyber — OpenAI**
  GPT-5.5 pushes deeper into coding and agent-style workflows. A cybersecurity variant, GPT-5.5-Cyber, is in limited preview for vetted security teams, trained to be more permissive on security-related tasks.
  Key specs: Priced at $2.25/million input tokens. Status: GPT-5.5 released; GPT-5.5-Cyber in limited preview.

- **Muse Spark — Meta (Superintelligence Labs)**
  Meta's first flagship LLM built under Chief AI Officer Alexandr Wang's newly formed Superintelligence Labs. Delivers competitive performance on multimodal perception, reasoning, health, and agentic tasks at a fraction of typical compute cost.
  Status: Released.

- **NVIDIA Ising — NVIDIA**
  The world's first family of open-source AI models purpose-built to accelerate quantum computing research and applications.
  Status: Released (open-source).

- **Mistral 128B — Mistral AI**
  Mistral's 128B flagship model launched with async cloud coding sessions and a new "Work" agentic mode in Le Chat.
  Key specs: 128B parameters. Status: Released (launched May 3, 2026).

- **Chinese Open-Weights Coding Models — Z.ai, MiniMax, Moonshot, DeepSeek**
  Four Chinese labs released open-weights coding models within a 12-day window: Z.ai's GLM-5.1, MiniMax M2.7, Moonshot's Kimi K2.6, and DeepSeek V4. Zhipu AI also released GLM-4.7, trained entirely on Huawei Ascend silicon with a 1.2% hallucination rate.
  Key specs: GLM-4.7 at $0.11/million input tokens. Status: Released (open-weights).

- **Gemini 3.1 Flash-Lite — Google**
  The most cost-efficient model in the Gemini 3.1 family, optimized for low-latency use cases.
  Key specs: $0.25/million tokens. Status: Public preview.

- **Anthropic "Dreaming" Technique — Anthropic**
  A new AI agent technique that lets autonomous systems review prior behavior, identify patterns, and improve future performance between sessions. Launching as a research preview as part of Anthropic's managed agents initiative.
  Status: Research preview.
