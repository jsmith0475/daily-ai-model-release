# AI Model Releases - June 6, 2026

## Top Updates

- **Google Gemma 4 QAT — Google (Open Source)**
  Quantization-aware training (QAT) variants of Gemma 4 optimized for on-device efficiency on mobile phones and laptops. These compressed models maintain quality while significantly reducing memory and compute requirements for edge deployment.
  *Specs: QAT variants of Gemma 4 (2.3B–31B parameter family) | Status: Released (June 5, 2026) / Open source*

- **Microsoft MAI-Code-1-Flash — Microsoft**
  Microsoft's inaugural in-house coding model, taking written natural-language descriptions and generating source code for applications and websites. Marks Microsoft's first significant move toward independence from OpenAI for frontier model capabilities. Available via Azure AI Foundry and directly in developer tools.
  *Status: Released (June 2, 2026) / Generally available*

- **Microsoft MAI-Thinking-1 — Microsoft**
  A high-efficiency reasoning model built for performance at low token cost, released alongside MAI-Code-1-Flash. Positioned to compete with OpenAI's o-series reasoning models. Currently in private preview through Microsoft Foundry; enterprise customers can request early access.
  *Status: Released (June 2, 2026) / Private preview via Microsoft Foundry*

- **MiniMax M3 — MiniMax**
  MiniMax's latest frontier model release, continuing the Chinese AI lab's push into the global competitive LLM landscape. Details on benchmarks and full capabilities are still emerging.
  *Status: Released (June 1, 2026)*

- **Google Gemini 3.5 Flash — Google**
  Already in production as of May 19, Gemini 3.5 Flash is now the active deployment standard for Google's speed-optimized tier. Benchmarks show it outperforms Gemini 3.1 Pro at approximately 4× the throughput.
  *Specs: $1.50 input / $9.00 output per million tokens | Context: Not yet confirmed | Status: Generally available*

- **Google Gemini 3.5 Pro — Google**
  Announced for June release but no specific launch date has been set. Targeted at reasoning-heavy workloads where Gemini 3.5 Flash showed regression compared to the 3.1 Pro tier. Expected to close the reasoning performance gap.
  *Status: Announced — release date TBD*

- **Claude Mythos 1 (Project Glasswing) — Anthropic**
  Anthropic's most capable model is in a tightly gated preview restricted to approximately 50 partner organizations including AWS, Apple, Google, Microsoft, NVIDIA, CrowdStrike, and JPMorgan Chase. Specialized for defensive cybersecurity vulnerability detection; reportedly found 23,019 vulnerabilities across 1,000+ open-source projects in testing.
  *Status: Restricted partner access only — no public release planned*

- **Grok 5 — xAI**
  Still in training as of this week, with prediction markets placing June release probability at 12–33%. Expected architecture is a Mixture-of-Experts (MoE) design at ~6 trillion parameters with a 1.5 million token context window and multimodal input support. Originally targeted for Q1 2026, then slipped to Q2.
  *Specs (rumored): ~6T parameter MoE, 1.5M token context, multimodal | Status: In training — June release uncertain*
