# AI Model Releases - April 24, 2026

### Top Updates

- **DeepSeek V4-Pro & V4-Flash (DeepSeek)** — Released today, DeepSeek's newest flagship arrives in two variants: V4-Pro (full-size) and V4-Flash (smaller, more economical). Both claim top-tier performance on coding benchmarks with significant advances in reasoning and agentic tasks. *Status: Released*

- **GPT-5.5 (OpenAI)** — An agentic model built to work through complex multi-step tasks autonomously by switching between tools mid-session. Priced at $5/1M input tokens and $30/1M output tokens (GPT-5.5 Pro: $30/$180). *Status: Released*

- **Gemini 3.1 Ultra (Google DeepMind)** — Features a 2-million token context window with native reasoning across text, image, audio, and video simultaneously. Ships with a sandboxed Code Execution tool that lets the model write, run, and test code mid-conversation. *Status: Released*

- **Meta Muse Spark (Meta)** — Meta's first flagship LLM developed under Chief AI Officer Alexandr Wang's Superintelligence Labs. Targets multimodal perception, reasoning, healthcare, and agentic tasks at lower compute cost than Llama 4 mid-size. *Status: Released*

- **Claude Opus 4.7 (Anthropic)** — Major version update released April 16. Leads real-world work evaluations; Claude Sonnet 4.6 also updated this week. *Status: Released*

- **NVIDIA Ising (NVIDIA)** — World's first open-source AI model family purpose-built to accelerate quantum computing, targeting quantum error correction and processor calibration. Unveiled at GTC 2026. *Status: Announced / Preview*

- **Luma Agents (Luma AI)** — New agentic product built on Luma's Uni-1 multimodal model. Coordinates multiple AI systems to generate end-to-end creative work across text, images, video, and audio. *Status: Released*

- **Huawei 950PR AI Chip (Huawei)** — New inference-optimized silicon with reported large orders from ByteDance and Alibaba; positions Huawei as a domestic alternative to NVIDIA in China. *Status: Announced*
