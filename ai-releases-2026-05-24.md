# AI Model Releases - May 24, 2026

> Daily briefing covering significant AI model releases, announcements, and launches from the past 24–48 hours.

---

## Top Updates

- **Gemini 3.5 Flash — Google**
  Google's first model in its newest series combining frontier intelligence with real-world action, announced and released at Google I/O 2026 (May 19–20). Now generally available via the Gemini API, Google AI Studio, Google Antigravity, and Android Studio. Outperforms Gemini 3.1 Pro on challenging coding and agentic benchmarks.
  - **Context window:** 1M tokens
  - **Benchmark:** 76.2% Terminal-Bench 2.1
  - **Pricing:** $1.50 / $9.00 per 1M input/output tokens
  - **Status:** ✅ Generally Available

- **Gemini Omni — Google**
  A new multimodal model series that combines Gemini's deep reasoning capabilities with rich content creation. Accepts image, audio, video, and text as input and can output video natively. Gemini Omni Flash is already available in Google Flow globally.
  - **Status:** 🔜 Gemini Omni (full) coming Summer 2026 to Google AI Pro & Ultra subscribers

- **Managed Agents in Gemini API — Google**
  A new agentic infrastructure layer where a single API call provisions a full remote Linux environment. Powered by the Antigravity agent built on Gemini 3.5 Flash. Enables complex multi-step AI agent tasks without custom infrastructure setup.
  - **Status:** ✅ Available via Gemini API

- **Thinking Machines "Interaction Models" — Thinking Machines (Mira Murati)**
  Founded by former OpenAI CTO Mira Murati, Thinking Machines announced a new class of "interaction models" designed for real-time, continuous human-AI collaboration. Models interpret audio, video, and text simultaneously while responding dynamically—targeting a more natural, low-latency collaboration experience.
  - **Status:** 📣 Announced

- **NVIDIA Ising — NVIDIA**
  NVIDIA unveiled Ising, described as the world's first family of open-source AI models purpose-built to accelerate quantum computing research and applications. Marks a significant push toward quantum-classical hybrid AI systems.
  - **Status:** 📣 Announced / Open-source

- **Qwen3 Coder Next — Alibaba**
  A code-specialist model variant from Alibaba's Qwen3 family, fine-tuned specifically for software engineering tasks, tool use, and agentic coding workflows.
  - **Release date:** May 18, 2026
  - **Status:** ✅ Released

- **MiniMax M2.5 Highspeed — MiniMax**
  A latency-optimized LLM targeting real-time chat, customer support, and low-latency agent applications. Positions as an efficiency-focused alternative for high-throughput, time-sensitive deployments.
  - **Release date:** May 18, 2026
  - **Status:** ✅ Released

- **SubQ Subquadratic LLM — SubQ**
  SubQ shipped the first commercial subquadratic LLM featuring a 12M token context window—a notable architectural milestone departing from standard transformer attention scaling. Aimed at applications requiring very long-context processing at lower compute cost.
  - **Context window:** 12M tokens
  - **Status:** ✅ Released (commercial)
