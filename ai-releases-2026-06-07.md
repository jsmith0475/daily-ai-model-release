# AI Model Releases - June 7, 2026

### Top Updates

- **Gemini 3.5 Flash — Google**
  Launched at Google I/O 2026, this model combines frontier intelligence with real-world action capabilities. Generally available now via the Gemini API in Google AI Studio and Android Studio. Google also introduced **Managed Agents** (powered by the new *Antigravity* agent), which provisions a remote Linux environment with a single API call so agents can plan, call tools, execute code, and browse the web.

- **MAI-Code-1-Flash — Microsoft**
  Announced at Microsoft Build 2026, this is Microsoft's first in-house coding model. It accepts written descriptions and generates full source code for applications and websites, signaling a move to reduce dependence on OpenAI for developer tooling. Available via Microsoft Foundry.

- **MAI-Thinking-1 — Microsoft**
  A dedicated reasoning model also announced at Build 2026, currently in private preview through Microsoft Foundry. Part of Microsoft's broader push to ship seven new MAI Models alongside Azure Cobalt 200 VMs (50% perf improvement for agentic workloads).

- **GPT-5.4 — OpenAI**
  Integrates advances from reasoning, coding, and agentic workflows, incorporating the coding capabilities of GPT-5.3-Codex. GPT-5.3-Codex (the underlying coding stack) runs ~25% faster than its predecessor and sets new benchmark highs on code generation tasks.

- **Real-Time Audio Models (3 models) — OpenAI**
  OpenAI launched three specialized real-time audio models targeting: conversational AI agents, language translation, and transcription. Designed for low-latency voice-first applications.

- **Ising — NVIDIA**
  The world's first family of open-source AI models purpose-built for quantum computing. Delivers up to **2.5× faster** and **3× more accurate** error-correction decoding compared to traditional approaches. Targets quantum hardware error mitigation at scale.

- **Intel AI Innovations (Computex 2026) — Intel**
  Unveiled at Computex 2026 (June 2–5), Intel announced chip-to-systems-level AI infrastructure including rackscale AI systems optimized for inference and agentic AI workloads at enterprise scale.

- **Claude Opus 4.8 — Anthropic** *(released May 28, within rolling 7-day window)*
  Latest flagship model from Anthropic. Part of the Claude 4.X family (alongside Sonnet 4.6 and Haiku 4.5). Details on benchmark improvements and context window updates available on Anthropic's release notes.
