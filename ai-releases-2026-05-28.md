# AI Model Releases - 2026-05-28

> Daily briefing compiled from web searches on May 28, 2026.

---

## Top Updates

- **Gemini 3.5 Flash — Google**
  The flagship release from Google I/O 2026 (May 18–21). Combines frontier intelligence with fast, low-cost inference; outperforms Gemini 3.1 Pro on challenging coding and agentic benchmarks. Generally available today via the Gemini API, Google AI Studio, Android Studio, and the new Antigravity agent platform.
  *Specs:* multimodal (text, image, audio, video input); designed for agentic workloads.
  *Status:* **Generally Available**

- **Gemini Omni Flash — Google**
  New Gemini Omni series model combining reasoning with creation. Accepts image, audio, video, and text input and generates video grounded in real-world knowledge. Available in Google Flow to Google AI subscribers globally.
  *Status:* **Generally Available**

- **Google Managed Agents (Antigravity) — Google**
  New agentic runtime in the Gemini API: a single API call provisions a remote Linux sandbox where an agent can reason, plan, call tools, execute code, and browse the web — powered by Gemini 3.5 Flash.
  *Status:* **Launched at Google I/O 2026**

- **GPT-5.5 Instant (default) — OpenAI**
  OpenAI promoted GPT-5.5 Instant to the default model endpoint following its April release (benchmark score 60.24). Represents the latest in OpenAI's frontier series optimized for speed and cost.
  *Status:* **Default / Generally Available**

- **OpenAI Deployment Company — OpenAI**
  New standalone company launched to help enterprises build and deploy AI systems, backed by over $4 billion in initial investment. Includes a self-serve Ads Manager platform for running campaigns inside ChatGPT.
  *Status:* **Announced & Launched**

- **NVIDIA Ising — NVIDIA**
  World's first family of open-source AI models purpose-built to accelerate quantum computing. Delivers up to 2.5× faster and 3× more accurate error-correction decoding compared to traditional approaches.
  *Status:* **Released (Open Source)**

- **ZAYA1-8B — Zyphra**
  8B Mixture-of-Experts model trained on AMD hardware. Activates only ~760M parameters per token at inference, delivering reasoning performance competitive with much larger models.
  *Specs:* 8B total params, ~760M active per token (MoE), AMD-native training.
  *Status:* **Released (May 6, 2026)**

- **Grok 4.3 — xAI**
  Updated Grok model with improved reasoning capabilities and enhanced real-time web access integration.
  *Status:* **Released (May 6, 2026)**

- **SubQ Subquadratic LLM — SubQ**
  First commercial deployment of a subquadratic (non-attention) large language model, featuring a 12 million token context window. Signals a potential architectural shift away from standard transformer attention.
  *Specs:* 12M token context window; subquadratic architecture.
  *Status:* **Released**

---

## Trend Notes

May 2026 marks a shift from raw scale to **architectural efficiency**: subquadratic attention alternatives, sparse MoE activations, and agentic runtimes are taking center stage over parameter count races. Google I/O dominated the week's announcements.
