# AI Model Releases - July 3, 2026

### Top Updates

- **Claude Sonnet 5 — Anthropic**
  The most capable and agentic Sonnet ever built, performing close to flagship Opus 4.8 on many tasks. Became the default model for all Free and Pro Claude users on July 1. Features a 1M token context window and scored 63.2% on the agentic coding benchmark vs. 58.1% for Sonnet 4.6. Introductory pricing at $2/M input tokens through August 31. *Status: Released*

- **Claude Fable 5 & Mythos 5 — Anthropic (Global Restoration)**
  After the US Department of Commerce lifted export controls on June 30, Anthropic began restoring full global access to Fable 5 and Mythos 5 on July 1. Access is now live across Claude.ai, Claude Platform, Claude Code, and Claude Cowork. *Status: Released (globally restored)*

- **GPT-5.3-Codex — OpenAI**
  OpenAI's most capable agentic coding model yet, combining the Codex and GPT-5 training stacks into a single unified model. Approximately 25% faster than its predecessor and sets new highs on key coding benchmarks. *Status: Released*

- **GPT-5.6 Sol — OpenAI**
  Next-generation model previewed on June 26, 2026, with enhanced agent capabilities. Additional details on inference chips and agentic features were shared at the preview event. *Status: Preview / Announced*

- **Microsoft MAI Model Family — Microsoft AI**
  Microsoft launched seven new in-house AI models. Highlights include **MAI-Thinking-1**, a flagship reasoning model that matches leading frontier models on software engineering benchmarks and advanced math, and **MAI-Code-1-Flash**, an inference-efficient agentic coding model built specifically for GitHub Copilot and VS Code. *Status: Released*

- **Gemini Omni Flash — Google**
  A natively multimodal model now in public API preview, enabling enterprises and developers to build custom dynamic video workflows. Positioned as Google's production-friendly multimodal workhorse. *Status: Public Preview*

- **Gemma 4 12B — Google**
  Google's latest open-weights model designed to run locally on consumer hardware using just 16 GB of RAM, enabling local AI agent workflows on laptops. *Status: Released (open weights)*

- **Gemini 3.1 Flash Image & Gemini 3 Pro Image — Google**
  Two new image-generation models released June 30. Gemini 3.1 Flash Image is priced at $0.50/M input / $3.00/M output tokens; Gemini 3 Pro Image at $2.00/M input / $12.00/M output tokens. *Status: Released*
