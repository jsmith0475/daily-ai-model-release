# AI Model Releases - 2026-05-22

## Top Updates

- **Gemini 3.5 Flash — Google**
  Launched at Google I/O 2026 (May 19–20), this model combines frontier-level intelligence with the speed of the Flash series, outperforming Gemini 3.1 Pro on challenging coding and agentic benchmarks. Priced at $1.50 / $9 per 1M tokens with a 1M-token context window. Generally available.

- **Gemini Omni + Managed Agents (Antigravity) — Google**
  Also unveiled at Google I/O 2026. Gemini Omni is a new multimodal model, while Google's Managed Agents API (powered by the "Antigravity" agent) provisions a remote Linux environment with a single API call, enabling full reasoning, planning, and tool use. Available via Gemini API.

- **Qwen3 Coder Next — Alibaba / Qwen**
  Released May 18–19, this next-generation code-specialist variant of Qwen3 is tuned for software engineering, agentic tool use, and repo-scale reasoning. Listed as available on LLM Gateway.

- **MiniMax M2.5 Highspeed — MiniMax AI**
  Released May 18. A high-throughput, low-latency LLM targeting real-time chat, customer support, and high-QPS backend workloads. Available via API.

- **Mistral 128B Flagship — Mistral AI**
  Mistral launched its 128B parameter flagship model with support for async cloud coding sessions and a new "Work" agentic mode integrated directly into Le Chat. Released / generally available.

- **NVIDIA Ising — NVIDIA**
  Described as the world's first family of open-source AI models purpose-built to accelerate quantum computing. Announced this week; availability details pending.

- **Anthropic "Dreaming" Agent Technique — Anthropic**
  Anthropic introduced a new AI agent capability called "dreaming," enabling autonomous systems to review prior behavior, identify patterns, and self-improve between sessions. Launching as a research preview.

- **Microsoft Agent 365 — Microsoft**
  Enterprise AI agent governance platform, extending agentic AI capabilities across business environments. Now generally available.
