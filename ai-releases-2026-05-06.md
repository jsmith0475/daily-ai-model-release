# AI Model Releases - May 6, 2026

### Top Updates

- **GPT-5.5 Instant – OpenAI**
  Released May 5, now the default model powering ChatGPT, replacing GPT-5.3 Instant. Optimized for speed and everyday tasks. API revenue for the GPT-5.5 family is reportedly growing more than 2× faster than any prior OpenAI model launch.
  *Status: Released*

- **GPT-5.5 & GPT-5.5 Pro – OpenAI**
  The flagship tier of the GPT-5.5 generation (launched April 23), featuring specialized "Thinking" and "Instant" modes with expanded context. Also announced for preview access on Amazon Bedrock.
  *Status: Released (GA + Bedrock preview)*

- **Gemini 3.1 Ultra – Google**
  2-million token context window with native multimodal understanding across text, image, audio, and video (no transcription intermediaries). Ships with a sandboxed Code Execution tool, letting the model write, run, and test code mid-conversation.
  *Status: Released*

- **Gemini 3.1 Flash-Lite – Google**
  Lightweight, cost-optimized sibling of Gemini 3.1 Ultra, priced at $0.25 per million tokens.
  *Status: Released*

- **Claude Opus 4.6 / Sonnet 4.6 / Haiku 4.5 – Anthropic**
  Opus 4.6 and Sonnet 4.6 both support 1-million token context at standard API pricing with no surcharge. Anthropic also released ten preconfigured financial-sector agents built on these models for investment banking, asset management, and insurance workflows.
  *Status: Released*

- **Kimi K2 Thinking – Moonshot AI**
  Open-weights reasoning model setting new records on reasoning benchmarks. Part of a wave of Chinese open-weights coding/reasoning models released within a 12-day window alongside Z.ai GLM-5.1, MiniMax M2.7, and DeepSeek V4.
  *Status: Released (open weights)*

- **DeepSeek V4 – DeepSeek**
  Newest flagship from DeepSeek (announced ~April 24), reaching the capability frontier for agentic engineering at significantly lower inference cost than Western counterparts. Follows up on the breakout DeepSeek R2 release from early 2025.
  *Status: Released*

- **NVIDIA Ising – NVIDIA**
  World's first family of open-source AI models purpose-built for quantum computing acceleration, targeting quantum error correction and processor calibration. Announced during National Robotics Week 2026.
  *Status: Announced / Released (open source)*
