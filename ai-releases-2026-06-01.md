# AI Model Releases - June 1, 2026

## Top Updates

- **GPT-5.3-Codex & GPT-5.4 — OpenAI**
  OpenAI launched GPT-5.3-Codex, their most capable agentic coding model, combining the Codex and GPT-5 training stacks for best-in-class code generation, reasoning, and tool use — approximately 25% faster than its predecessor with new benchmark highs. GPT-5.4 builds on this, incorporating the coding gains while improving multi-tool agentic workflows across professional tasks.
  *Status: Released / Available*

- **Claude Opus 4.8 — Anthropic**
  Anthropic's newest flagship model, released May 28, 2026. Positioned as the most capable model in the Claude 4 family, targeting complex reasoning and agentic task execution. Successor to Claude Opus 4.7.
  *Status: Released / Available via API and Claude.ai*

- **Gemini 3.5 Flash — Google**
  Launched at Google I/O 2026 (May 19), Gemini 3.5 Flash is Google's first model in the "frontier intelligence with action" series — multimodal (text, image, audio, video), with a 1M token context window and output tokens 4x faster than comparable flagship models. Outperforms Gemini 3.1 Pro on Terminal-Bench 2.1 (76.2%) and challenging agentic benchmarks. AA Intelligence Index: 55.3. Pricing: $1.50 input / $9.00 output per 1M tokens.
  *Status: Released / Generally available via Gemini API, Google AI Studio, Android Studio, and Google Antigravity*

- **Qwen 3.7 Max — Alibaba Cloud**
  Released alongside Gemini 3.5 Flash on May 19, Qwen 3.7 Max is a professional-tier reasoning model with a 1M token context window. Tops the AA Intelligence Index at 56.6 among currently tracked public models. API-only. Pricing: $2.50 input / $7.50 output per 1M tokens.
  *Status: Released / API access*

- **Managed Agents in Gemini API — Google**
  Announced at Google I/O 2026, this new API capability provisions a remote Linux sandbox where Gemini agents can reason, plan, call tools, execute code, manage files, and browse the web in an isolated environment — effectively a hosted agentic runtime with no local infrastructure required.
  *Status: Released / Generally available*

- **NVIDIA Ising — NVIDIA**
  NVIDIA unveiled Ising, the world's first family of open-source AI models purpose-built to accelerate quantum computing. Specifically targets quantum error correction and processor calibration workflows, bridging classical AI and quantum hardware development.
  *Status: Announced / Open source*

- **Grok Build 0.1 CLI — xAI**
  xAI released a beta CLI for Grok Build (May 14), an agentic developer tool designed to bring Grok's reasoning capabilities directly into coding and software engineering workflows. Follows the earlier general Grok 4.3 update (May 6).
  *Status: Beta / Developer preview*

- **China Mobile JT-35B-Flash**
  A 35B-parameter text model from China Mobile with a 256K token context window. Freely available via API. AA Intelligence Index: 36.1. Represents continued growth in enterprise-backed open-access model releases from China.
  *Status: Released / Free API*

- **OpenBMB MiniCPM-V 4.6 1.3B — OpenBMB**
  Compact open-source multimodal model (1.3B parameters, 262K context window) supporting text, image, and video inputs. Released under Apache 2.0, designed for on-device and edge deployment. Demonstrates strong capability-per-parameter efficiency for its class.
  *Status: Released / Open source (Apache 2.0)*
