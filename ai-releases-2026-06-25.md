# AI Model Releases - June 25, 2026

## Top Updates

- **Nex N2 Pro — Nex-AGI**
  Released within the last 24 hours; a new frontier-competitive LLM from Nex-AGI aimed at reasoning and agentic tasks. Full specs and benchmarks pending wider coverage.
  *Status: Released*

- **GLM-5.2 — Z.ai (Zhipu AI)**
  Independent benchmarks rank GLM-5.2 as the most capable openly available language model on the market, released under the permissive MIT license with no usage restrictions or regional locks. Available via providers such as OpenRouter at ~$1.40/M input / $4.40/M output tokens.
  *Status: Released (open-weight, MIT license)*

- **GPT-5.3-Codex — OpenAI**
  OpenAI's most capable agentic coding model, combining the Codex and GPT-5 training stacks for best-in-class code generation and reasoning. Approximately 25% faster than its predecessor and sets new highs on key coding benchmarks.
  *Status: Released*

- **Claude Fable 5 & Mythos 5 — Anthropic**
  Launched in early June 2026, representing a significant capability tier above Claude Opus 4.8. Claude Fable 5 leads the coding leaderboard (coding index: 59.0); Claude Mythos Preview leads GPQA Diamond at 94.6%. Note: reports emerged of a temporary government review following alleged guardrail bypass research by Amazon.
  *Status: Released (subject to ongoing regulatory review)*

- **Kimi K2.7 Code — Moonshot AI (China)**
  Released June 12, 2026; a coding-first successor optimized for software engineering tasks and agentic workflows. Available on major inference platforms.
  *Status: Released*

- **Gemini 3.5 Pro — Google DeepMind**
  Features a 2-million-token context window and a specialized "Deep Think" cognitive mode for extended reasoning. Confirmed at Google I/O (late May) for June release window.
  *Status: Released / Rolling out*

- **MiniMax M3 — MiniMax**
  Released June 1, 2026. Achieves 59.0% on SWE-bench Pro, includes native image and video input, and a 1-million-token context window. Priced at $0.30/M input / $1.20/M output tokens — highly competitive on cost.
  *Status: Released*

- **MAI-Thinking-1 — Microsoft**
  Unveiled at Microsoft Build 2026 as part of the MAI (Microsoft AI) model family. A 1T total / 35B active MoE reasoning model trained from scratch on 33T tokens without distillation — Microsoft's first in-house frontier reasoning model.
  *Status: Announced / Preview*
