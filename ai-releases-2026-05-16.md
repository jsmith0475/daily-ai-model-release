# AI Model Releases - May 16, 2026

## Top Updates

- **GPT-5.5 / GPT-5.5 Instant — OpenAI**
  OpenAI's latest flagship, released April 23 and set as the ChatGPT default on May 5, pushes deeper into agentic coding, computer use, knowledge work, and scientific research. It is positioned as OpenAI's "smartest and most intuitive model yet." | *Status: Released*

- **GPT-5.3-Codex — OpenAI**
  OpenAI's most capable agentic coding model to date, combining advanced reasoning with frontier coding performance. It is the first OpenAI model classified as "High capability" for cybersecurity. | *Status: Released*

- **Gemini 3.1 Ultra — Google DeepMind**
  Google's most significant model release of the year features a **2-million token context window** and native multimodal processing across text, image, audio, and video — no transcription intermediaries. Gemini 3.1 Pro ships a 2× jump in hard multi-step reasoning. Gemini 3.1 Flash Lite hit API gateways on May 8. | *Status: Released*

- **Mistral 128B — Mistral AI**
  Launched May 3, Mistral's 128B flagship adds async cloud coding sessions and a new **Work agentic mode** in Le Chat, targeting enterprise autonomous task execution. | *Status: Released*

- **Meta Muse Spark — Meta Superintelligence Labs**
  Meta's first proprietary flagship LLM built under Chief AI Officer Alexandr Wang's newly formed Superintelligence Labs. Delivers competitive performance on multimodal perception, reasoning, health tasks, and agentic tasks at significantly lower compute cost than comparable frontier models. | *Status: Announced / Early Access*

- **NVIDIA Ising — NVIDIA**
  The world's first family of open-source AI models purpose-built to accelerate quantum computing research and simulation workloads. | *Status: Announced*

- **Thinking Machines "Interaction Models" — Thinking Machines (Mira Murati)**
  Founded by former OpenAI CTO Mira Murati, Thinking Machines announced a new class of "interaction models" enabling real-time human-AI collaboration that simultaneously interprets audio, video, and text without turn-based latency. | *Status: Announced*

- **SubQ Subquadratic LLM — SubQ**
  The first commercial subquadratic large language model, featuring a **12-million token context window** and architectural improvements that avoid the quadratic attention scaling bottleneck. | *Status: Released*
