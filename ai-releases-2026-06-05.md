# AI Model Releases - June 5, 2026

## Top Updates

- **GPT-5.5 Instant — OpenAI**
  Launched as the new default model in ChatGPT, replacing GPT-5.3 Instant. Brings sharper accuracy, more concise responses, stronger image and STEM assistance, improved web search integration, and richer context awareness for Plus and Pro subscribers.
  _Status: Released (default for all ChatGPT users)_

- **GPT-5.4 mini — OpenAI**
  A lightweight reasoning-focused model now rolling out to Free and Go tier ChatGPT users via the "Thinking" feature toggle. Targets accessible, cost-efficient inference.
  _Status: Rolling out_

- **GPT-5.3-Codex — OpenAI**
  Combines the Codex and GPT-5 training stacks into a unified coding-agent model. Approximately 25% faster than its predecessor and sets new coding benchmarks. Also available on AWS as of June 2, 2026.
  _Status: Released_

- **MAI-Code-1-Flash — Microsoft**
  Microsoft's inaugural in-house coding model, announced at Microsoft Build 2026 (June 2–3, San Francisco). Accepts natural-language descriptions and generates source code for applications and websites; designed to reduce developer reliance on third-party model APIs.
  _Status: Announced / Preview_

- **MAI-Thinking-1 — Microsoft**
  A reasoning model also unveiled at Build 2026, optimized for high performance at low token cost. Targets enterprise workloads requiring multi-step reasoning without premium pricing.
  _Status: Announced / Preview_

- **Gemini 3.5 Flash — Google**
  The latest addition to Google's Gemini 3.x family, continuing the benchmark momentum from earlier in 2026. Emphasized at Google I/O 2026; details on context window and parameter count pending full release notes.
  _Status: Released_

- **Ising — NVIDIA**
  Described as the world's first family of open-source AI models purpose-built for quantum computing. Delivers up to 2.5× faster and 3× more accurate quantum error-correction decoding compared to traditional approaches.
  _Status: Released (open source)_

- **Grok Build 0.1 — xAI**
  Early developer-facing release in the Grok 4.x line, with multi-agent variants also in testing. Limited details available; positioned for agentic and autonomous task workflows.
  _Status: Early access / Preview_

- **Hunyuan HY3 Preview — Tencent**
  Preview release of Tencent's next-generation Hunyuan model. Multimodal capabilities emphasized; full specs pending general availability announcement.
  _Status: Preview_

- **Qwen 3.7 Max — Alibaba / Qwen Team**
  Open-source release of the latest Qwen 3.x model. Continues Alibaba's push to compete in the open-weight frontier model space.
  _Status: Released (open source)_
