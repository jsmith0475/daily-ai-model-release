# AI Model Releases - 2026-05-26

> **Coverage:** Past 24–48 hours plus major recent announcements (Google I/O 2026, week of May 19–26)

---

## Top Updates

- **Gemini 3.5 Flash — Google DeepMind** *(Released: May 19, 2026 — Generally Available)*
  Google's newest and fastest frontier model, optimized for agentic workflows and coding tasks. Outperforms Gemini 3.1 Pro on Terminal-Bench 2.1 (76.2% vs 70.3%), MCP Atlas (83.6% vs 78.2%), and Finance Agent v2 (57.9% vs 43.0%) benchmarks, while running 4× faster.
  - **Context window:** 1,048,576 input tokens (~786K words) / 65,536 output tokens
  - **Inputs:** Text, image, audio, video, PDF (multimodal)
  - **Pricing:** $1.50 / $9.00 per million input/output tokens (cached input: $0.15/M)
  - **Status:** Generally available via Gemini API, Google AI Studio, Android Studio

- **Gemini Omni — Google DeepMind** *(Announced: May 19, 2026)*
  A new multimodal model series that accepts any input (image, audio, video, text) and can output video grounded in real-world knowledge — representing a major leap in multimodal generation and world understanding.
  - **Status:** Announced at Google I/O 2026; availability details TBA

- **Gemma 4 — Google DeepMind** *(Released: May 2026 — Open Source)*
  A family of four open-weight models purpose-built for advanced reasoning and agentic workflows: E2B, E4B, 26B MoE, and 31B Dense variants. All licensed under Apache 2.0.
  - **Sizes:** 2B, 4B, 26B (MoE), 31B (Dense)
  - **License:** Apache 2.0
  - **Status:** Released / Open source

- **Gemini Managed Agents — Google** *(Announced: May 19, 2026)*
  A new Gemini API capability that provisions a remote Linux sandbox environment via a single API call, enabling agents to reason, plan, call tools, execute code, manage files, and browse the web in isolation.
  - **Status:** Launching via Gemini API

- **NVIDIA Ising — NVIDIA** *(Announced: May 2026)*
  The world's first family of open-source AI models purpose-built to accelerate quantum computing, specifically for error-correction decoding. Delivers up to 2.5× faster and 3× more accurate performance compared to traditional approaches.
  - **License:** Open source
  - **Status:** Announced

- **Mistral 128B Flagship — Mistral AI** *(Released: May 2026)*
  Mistral's new 128B-parameter flagship model with async cloud coding sessions and a new "Work" agentic mode in Le Chat for multi-step task automation.
  - **Parameters:** 128B
  - **Status:** Released; available via Le Chat and API

- **Grok Build 0.1 — xAI** *(Released: May 2026)*
  xAI's latest Grok model release aimed at developers, now available via API.
  - **Pricing:** $1.00 / $2.00 per million input/output tokens
  - **Status:** Released / Available via API

- **Anthropic "Dreaming" System — Anthropic** *(Announced: May 2026)*
  A novel self-improvement framework for AI agents that allows autonomous systems to review prior behavior, identify patterns, and improve future performance. Initially launching as a research preview targeting long-running workflows in coding, finance, and law.
  - **Status:** Research preview

- **SubQ Subquadratic LLM — SubQ** *(Released: May 2026)*
  The first commercial subquadratic-attention large language model, breaking away from the standard transformer attention bottleneck and enabling an unprecedented 12 million token context window.
  - **Context window:** 12M tokens
  - **Status:** Released (commercial)

- **Qwen 3.7 Max — Alibaba** *(Released: May 2026)*
  Alibaba's latest Qwen flagship model with enhanced multilingual support, continuing the Qwen 3.x series expansion.
  - **Status:** Released
